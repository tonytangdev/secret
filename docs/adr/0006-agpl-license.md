# AGPL-3.0 license

The repo is public so anyone can check the security claims, and it may make money someday. MIT would let anyone run a closed, paid copy, and source-available licenses (FSL) or no license weaken the "check the code yourself" story for a security tool. AGPL-3.0 is OSI open source and requires anyone who runs a modified version as a service to publish their source. As sole copyright holder, Tony can still add paid features or relicense.

## Consequences

- Require a CLA before accepting outside contributions, or relicensing becomes impossible.
